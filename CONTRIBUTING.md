# Contributing

This repo is the website source of truth. Create UI changes under `src/` and keep `standalone-demo/` as a presentation backup. Do not commit API keys, database credentials, player personal data, or real game dumps. For feature branches use `feature/<short-name>` and open PRs to `main` after `npm run build`. Keep new modules fully typed; remove existing `@ts-nocheck` as pieces of the prototype are refactored. Mark mock data clearly.
